# mp-cli

Инструмент для загрузки, распаковки (частичной и полной) и просмотра содержимого Minecraft сборок.

`mp-cli` можно использовать внутри других программ (есть вывод информации в JSON формате)

# Планы развития

- `v0.1.0`:
  - Возможность загрузки сборок по ссылке
  - Поддержка простого `.zip` формата:
    - Полная и частичная распаковка
    - Вывод информации о сборке: `info.json` + содержимое архива
- `v0.2.0`: Расширение функционала:
  - Создание сборок (просто `.zip` архив)
  - Создание `info.json` файла
- `v0.3.0`: Минимальная поддержка `.mrpack`:
  - Полная распаковка (без загрузки контента)
  - Вывод информации о сборке (в том числе из метаданных)
